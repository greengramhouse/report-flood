# แบบรายงานนักเรียนที่ได้รับผลกระทบจากอุทกภัย (งบเงินอุดหนุน)

เว็บแอปสำหรับโรงเรียนเดียว ครูประจำชั้นเลือกห้องของตัวเอง ระบบจะดึงรายชื่อนักเรียนห้องนั้นจาก API รายชื่อนักเรียนมาให้
ครูติ๊กคนที่ได้รับผลกระทบแล้วบันทึก ข้อมูลเก็บใน Google Sheet
จากนั้นดาวน์โหลดไฟล์ Excel ตามแบบฟอร์มต้นฉบับได้ทั้งรายห้องและรวมทั้งโรงเรียน ไฟล์มี 2 แผ่น คือแบบหมายเลข 1 (รายชื่อนักเรียน) และแบบหมายเลข 2 (สรุปรายชั้น)

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ (HTML + Tailwind) |
| `assets/app.js` | การทำงานของหน้าเว็บ: เลือกห้อง, ติ๊กนักเรียน, ตรวจข้อมูล, บันทึก, สรุปทั้งโรงเรียน, ดาวน์โหลด |
| `assets/report.js` | สร้างไฟล์ Excel โดยเติมข้อมูลลงใน `template.xlsx` |
| `assets/config.js` | **ตั้งค่า:** รหัสและชื่อโรงเรียน, URL API รายชื่อนักเรียน, URL Apps Script |
| `template.xlsx` | สำเนาของ `แบบรายงาน_Excel.xlsx` ใช้เป็นแม่แบบ (ห้ามลบ) |
| `assets/tailwind.css` | CSS ที่ build จาก Tailwind ไว้แล้ว (ไม่ต้องคอมไพล์บนมือถือ) |
| `tailwind/` | ไฟล์ตั้งค่าสำหรับ build `assets/tailwind.css` ใหม่ |
| `code.js` | โค้ดฝั่ง Google Apps Script (นำไปวางใน `code.gs`) |

## ขั้นตอนติดตั้ง

### 1) Google Sheet + Apps Script
1. สร้าง Google Sheet ใหม่ (แยกจากชีตรายชื่อนักเรียน) แล้วไปที่เมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิมใน `code.gs` แล้ววางโค้ดทั้งหมดจาก `code.js`
3. เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้** (ครั้งแรกจะถามสิทธิ์ ให้กดอนุญาต)
   ระบบจะสร้างชีต `Rooms`, `Students` และ `Settings`
4. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่** แล้วเลือกประเภท **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
5. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

> ถ้าแก้ไข `code.gs` ภายหลัง ให้ไปที่ **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข (ไอคอนดินสอ) → เวอร์ชัน: เวอร์ชันใหม่**
> ถ้าสร้างการทำให้ใช้งานได้รายการใหม่แทน URL จะเปลี่ยน และต้องแก้ไฟล์ config.js ใหม่

### 2) ตั้งค่าหน้าเว็บ (`assets/config.js`)

```js
window.APP_CONFIG = {
  SCHOOL_CODE: '1019xxxxxx',                // รหัสโรงเรียน 10 หลัก
  SCHOOL_NAME: 'โรงเรียน...',
  STUDENT_API_URL: 'https://script.google.com/macros/s/AKfycbwGK.../exec',  // ใส่ไว้ให้แล้ว
  API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec'               // URL จากขั้นตอนที่ 1
};
```

### 3) Deploy บน GitHub Pages
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. ไปที่ **Settings → Pages** เลือก Source เป็น **Deploy from a branch** แล้วเลือก branch `main` โฟลเดอร์ `/ (root)`
3. รอประมาณ 1 นาที จะได้ลิงก์รูปแบบ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
   ลิงก์ที่เปิดหน้าสรุปทั้งโรงเรียนโดยตรงคือ `.../#summary`

## API รายชื่อนักเรียนที่ใช้
หน้าเว็บอ่านข้อมูล JSON ที่เป็น array ของนักเรียน โดยใช้ฟิลด์ต่อไปนี้
`classroom` (ห้อง เช่น `อนุบาล2`, `ป.1`, `ป.1/2`), `no`, `student_id`, `citizen_id`, `prefix`, `first_name`, `last_name`

- ชื่อห้องจะถูกแปลงเป็นชั้นตามแบบฟอร์มให้อัตโนมัติ เช่น `อนุบาล2` → `อ.2` และ `ป.1/2` → `ป.1` (ในแบบ 1 จะแสดงเป็น `ป.1/2`)
- นักเรียนที่เลขประจำตัวไม่ครบ 13 หลัก ครูแก้เลขในหน้าเว็บได้ โดยไม่กระทบข้อมูลต้นทาง

## โครงสร้างข้อมูลใน Google Sheet

- **Rooms**: 1 แถวต่อ 1 ห้อง เก็บครูผู้รายงาน จำนวนนักเรียนแยกตามประเภทความเสียหาย และเวลาที่บันทึกล่าสุด
- **Students**: 1 แถวต่อนักเรียนที่ได้รับผลกระทบ คอลัมน์ "ที่มา" บอกว่ามาจาก API หรือครูเพิ่มเอง
- **Settings**: ชื่อและเบอร์โทรของผู้อำนวยการและครูผู้รับผิดชอบ ใช้ในรายงานภาพรวม

เมื่อครูบันทึกห้องซ้ำ ระบบจะเขียนทับเฉพาะข้อมูลของห้องนั้น ไม่กระทบห้องอื่น

## วิธีใช้

**ครูประจำชั้น** (แท็บ "กรอกรายห้อง")
1. กดเลือกห้องของตัวเอง ถ้าห้องนั้นเคยบันทึกไว้แล้ว ระบบจะโหลดการติ๊กเดิมมาให้
2. ติ๊กช่องหนังสือเรียน อุปกรณ์การเรียน หรือเครื่องแบบ ให้นักเรียนที่ได้รับผลกระทบ
   ถ้าเสียหายทั้งห้อง ใช้ปุ่ม "ติ๊กทุกคนในห้อง" ได้ ถ้ามีนักเรียนที่ไม่อยู่ในรายชื่อ ให้กด "+ เพิ่มนักเรียนที่ไม่อยู่ในรายชื่อ"
3. กรอกชื่อและเบอร์โทรของครูผู้รายงาน แล้วกด **บันทึกห้องนี้**
   ถ้าห้องไม่มีนักเรียนได้รับผลกระทบ ก็กดบันทึกได้ ระบบจะนับว่าห้องนั้นส่งแล้ว (0 คน)
4. กด **ดาวน์โหลด Excel ห้องนี้** ถ้าต้องการไฟล์ของห้องตัวเอง

**ผู้รับผิดชอบโครงการ** (แท็บ "สรุปทั้งโรงเรียน")
1. ดูว่าห้องไหนส่งแล้วหรือยังไม่ส่ง
2. กรอกชื่อผู้อำนวยการและครูผู้รับผิดชอบ แล้วกด **บันทึกข้อมูลผู้ลงนาม**
   ชื่อผู้อำนวยการจะถูกใช้ในไฟล์รายห้องด้วย
3. กด **ดาวน์โหลด Excel ทั้งโรงเรียน** เพื่อได้ไฟล์เดียวที่รวมทุกห้อง สำหรับส่งเขต

## ความเร็วเมื่อเปิดพร้อมกันหลายคน
- หน้าเว็บจำรายชื่อนักเรียนไว้ในเครื่อง เปิดครั้งต่อไปปุ่มห้องจะขึ้นทันที แล้วอัปเดตรายชื่อล่าสุดเบื้องหลัง
- ปุ่มห้องไม่รอสถานะการส่ง สถานะ "ส่งแล้ว/ยังไม่ส่ง" จะตามมาเมื่อเซิร์ฟเวอร์ตอบ
- ถ้าเซิร์ฟเวอร์ตอบช้าหรือล้มเหลว ระบบจะลองใหม่อัตโนมัติสูงสุด 3 ครั้ง
- `code.gs` เก็บผลไว้ใน CacheService 5 นาที และล้าง cache ทันทีเมื่อมีการบันทึก

## แก้ไขหน้าตา (Tailwind)
ถ้าเพิ่มหรือเปลี่ยน class ของ Tailwind ใน `index.html` หรือ `assets/app.js` ต้อง build CSS ใหม่ (ต้องมี Node.js)

```bash
npx tailwindcss@3.4.16 -c tailwind/tailwind.config.js -i tailwind/input.css -o assets/tailwind.css --minify
```

## หมายเหตุ
- ไฟล์ Excel ใช้แม่แบบเดิม ฟอนต์ เส้นตาราง และกล่องลงชื่อจึงเหมือนต้นฉบับ ถ้านักเรียนเกิน 12 คน ระบบจะเพิ่มแถวและแบ่งหน้าให้เอง โดยหัวตารางจะพิมพ์ซ้ำทุกหน้า
- **ความเป็นส่วนตัว:** หน้าเว็บไม่มีรหัสผ่าน ใครที่มีลิงก์ก็ดูและแก้ไขข้อมูลได้ ซึ่งรวมถึงเลขประจำตัว 13 หลักของนักเรียน และ API รายชื่อนักเรียนเปิดให้ทุกคนอ่านได้อยู่แล้ว ควรส่งลิงก์ให้เฉพาะครูในโรงเรียน
